# Rubic Glossary

**amountToSend** — deposit-trade field: the amount the user manually transfers to the deposit address (Ch04)
**approvalAddress** — provider-specific ERC-20 spender in the swap response; approve against THIS, never a hardcoded router (Ch04)
**apiKey** — optional Rubic API key from BD (`t.me/RubicPartnership`); raises rate limits (Ch01)
**blockchainId** — numeric chain id in routing/fee objects (EVM only; Solana e.g. 7565164) (Ch03)
**BlockchainName** — Rubic's chain identifier string: `'ETH'`, `'BSC'`, `'POLYGON'`, `'SOLANA'`, `'TRON'`, `'TON'`, `'BITCOIN'` (Ch03)
**chain type** — `'evm'`, `'solana'`, `'tron'`, `'ton'`, `'bitcoin'`, `'sui'`, `'cosmos'` (Ch06)
**claim** — SDK method building the Arbitrum Bridge claim transaction (ETHEREUM ↔ ARBITRUM) (Ch05)
**cross-chain swap** — token swap across different blockchains via bridges/aggregators (Ch03)
**CrossChainTradeType** — the union type of cross-chain providers: symbiosis, lifi, dln, bridgers, multichain, xy, celer_bridge, changenow, stargate, stargate_v2, arbitrum, squidrouter, scroll_bridge, taiko_bridge, rango, pulsechain_bridge, orbiter_bridge, owl_to_bridge, layerzero, archon_bridge, meson, eddy_bridge, router (Ch06)
**deposit trade** — swap executed by sending funds to a deposit address; no source-wallet signature required (Ch03)
**destinationTxHash** — destination-chain transaction hash; available on SUCCESS (Ch05)
**enableChecks** — balance/gas validation before building the swap tx; default `true` (Ch03)
**ErrorDto** — `{ code: number, reason: string, data?: object }` (Ch07)
**estimate** — quote/swap sub-object: destinationTokenAmount, destinationTokenMinAmount, destinationUsdAmount, durationInMinutes, priceImpact, slippage (Ch03)
**foreignBlacklist** — excludes foreign providers inside an aggregator: `{ lifi?: string[], rango?: string[] }` (Ch03)
**FeesDto** — gasTokenFees (gas/protocol/provider/nativeToken) + percentFees (percent + token) (Ch03)
**getStatusExtended** — one-shot status fetch: `{ id, srcTxHash? }` → StatusResponseInterface (Ch05)
**healthcheck** — SDK method; returns `'I am alive'` when the API is up (Ch06)
**INDETERMINATE** — terminal status: status cannot be determined (Ch05)
**integratorAddress** — whitelisted EVM fee-recipient wallet(s); crossChain + onChain variants (Ch02)
**LONG_PENDING** — status: taking longer than expected, still processing (Ch05)
**MCP** — Model Context Protocol server (`@cryptorubic/mcp`) exposing Rubic to AI agents (Ch08)
**native sentinel** — `0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE` in the SDK; REST API uses `0x0000...0` (Ch01)
**nativeBlacklist** — excludes native providers by CrossChainTradeType (Ch03)
**OnChainTradeType** — union of 130+ on-chain DEX identifiers (UNISWAP_V2, PANCAKE_SWAP, ONE_INCH, ODOS, JUPITER, ...) (Ch06)
**on-chain swap** — token swap within one blockchain via DEXes (Ch03)
**PENDING** — status: transaction received, waiting for confirmation (Ch05)
**percentFees** — protocol + integrator percentage fees, charged in a token (Ch08)
**permit2** — Uniswap Permit2 approval flow; error 3002 NEED_PERMIT2_APPROVE (Ch07)
**preferredProvider** — forces one provider for calculation (Ch03)
**Private Mode** — Rubic feature routing through privacy providers (ClearSwap, Houdini Swap, RocketX, Railgun) (Ch08)
**proxyAvailable** — chain supports fee collection via Rubic proxy contracts (Ch06)
**quote** — indicative route calculation; no execution; expires (error 1003) (Ch03)
**quoteAll** — all routes sorted best-first: `{ routes[], failed? }` (Ch03)
**quoteBest** — single best route; returns QuoteResponseInterface with `id` (Ch03)
**quoteDepositTrades** — deposit-based routes only; `fromAddress` optional (Ch03)
**READY_TO_CLAIM** — terminal status: funds ready to claim on destination (Arbitrum Bridge, manual) (Ch05)
**receiver** — recipient address on the destination chain (Ch03)
**referrer** — required integration identifier; sent as `referer` in every request (Ch01)
**REVERT / REVERTED** — terminal statuses: transaction reverted; refund issued per provider (Ch05)
**RoutingDto** — `{ type: 'cross-chain'|'on-chain', provider: string, path: TokenAmountDto[] }` (Ch03)
**RubicApiError** — typed SDK error: name, message (=reason), code, reason, data, traceId (Ch07)
**rubic-search-tokens (MCP)** — searches tokens by symbol/name/address (Ch08)
**showDangerousRoutes** — include routes with priceImpact >20% / <-5% or slippage >20%; default false (Ch03)
**showFailedRoutes** — include failed routes in quoteAll; default false (Ch03)
**skipFeeProviders** — only routes where provider fixed fee = 0 (Ch03)
**slippage** — max slippage percent; `1` = 1%; default per quote (Ch03)
**srcTxHash** — source-chain tx hash; required for status polling of decentralized providers (Ch05)
**swap** — builds tx data for a quoted route; requires id + fromAddress + receiver (Ch04)
**swapBest** — quote + swap in one call (no quote preview) (Ch04)
**swapDepositTrade** — deposit-based swap; returns depositAddress + amountToSend (Ch04)
**swapType** — `'cross-chain'` or `'on-chain'` (Ch03)
**traceId** — internal request id on errors; include in bug reports (Ch07)
**TransactionDto** — `{ approvalAddress?, data?, to?, value?, depositAddress?, extraFields?, feeLimit? }` (Ch04)
**WAITING_FOR_TRUSTLINE** — status: XRP/Stellar trustline pending (Ch05)
**waitForStatus** — polling helper: interval 3s, timeout 300s, onStatusUpdate callback (Ch05)
**warnings** — non-fatal ErrorDto array in quote/swap responses (Ch03)
